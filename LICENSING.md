# Licensing

Ableton Y Bridge is offered under a **dual licence**.

## 1. Open source: AGPL-3.0

By default this code is licensed under the **GNU Affero General Public License v3.0 only**
(full text in [`LICENSE`](LICENSE)). You may use, study, change and share it on these terms:

- **Copyleft:** works based on it must also be licensed under AGPL-3.0.
- **Network clause (section 13):** if you run a *modified* version as a service that others
  use over a network, you must offer them the complete source of your version.
- Licence and copyright notices must be kept.

This is the right choice for private studios, research, teaching and any project that stays
open itself.

## 2. Commercial licence

If you want to build the code into a **closed or commercial product** without meeting the
AGPL obligations (copyleft, source disclosure, network clause), you need a **commercial
licence**. It lifts those obligations for your product, for a fee or by agreement.

**Requests:** by e-mail to **yoka@provolution.org** or through a
[GitHub issue](https://github.com/yokadeeds-dev/ableton-y-bridge/issues).

## Why dual?

The bridge stays free and open for the community, while companies that want to close it or
resell it contribute fairly.

## Shared work with other projects

Specifications and conformance tests that are developed together with other projects (for
example a common interface for Ableton MCP servers) live in **separate repositories under
the MIT licence**, so that projects under other licences can use them as well. The code of
this repository stays under the terms above.

## Contributions

External contributions need the contributor agreement in [`CONTRIBUTING.md`](CONTRIBUTING.md).
Without it, outside code cannot be included in the commercial licence.
